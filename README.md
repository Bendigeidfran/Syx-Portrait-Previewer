# Songs of Syx portrait previewer

A static page that composites a race portrait the way Songs of Syx does. Open `index.html`, or the GitHub Pages site, and drop in your own game and mod files. Nothing is uploaded, and this repo contains no game art.

1. Drop the game's `base/data.zip` onto the page.
2. Optionally, drop a mod's main folder, the one holding `_Info.txt`. Drop one mod at a time.

Mods are numbered like the launcher's load order, and the lowest number wins. Roll and Randomise read mod folders again, so edits to your art show up without dropping them again.
