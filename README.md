# Songs of Syx portrait previewer

A static page that composites a race portrait the way Songs of Syx does. Open `index.html`, or the GitHub Pages site, and pick files from your own game or mod. Nothing is uploaded, and this repo contains no game art.

Add the face images first, then the sprite text. Add vanilla before a mod: a later file replaces tags in an earlier file of the same name, and a later image replaces an image of the same name.

- Face folder: `assets/sprite/race/face`
- Sprite files: `assets/init/race/sprite/*.txt`
- Sprite folder: `assets/init/race/sprite`
